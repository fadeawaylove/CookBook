04. 我的交易设置 (My Setup)

概述​

本章节介绍 Al Brooks 个人的交易设置和工作环境，包括他的办公室配置、图表设置和使用的指标。

1. 交易心态​

我的工作是：做我热爱的事情来赚钱​

  • 把钱从你的账户转移到我的账户
  • 你的工作是把钱从我的账户拿走！
  • 这就是我们在玩的游戏！

2. 家庭办公室设置​

硬件配置​

  • 笔记本电脑（第二台电脑用于聊天室）
  • 百叶窗关闭，不接电话，不看电视
  • 忽略新闻和专家意见
  • 不想有任何干扰或他人观点
  • 保持高度专注

为什么这样设置​

交易需要绝对专注。任何外部干扰都可能影响判断力。关闭百叶窗、不接电话、不看电视都是为了创造一个纯粹的交易环境。

3. 主要交易图表：5分钟 S&P500 ES Emini​

多时间框架EMA设置​

在5分钟图表上同时显示：

  • 60分钟 20根K线 EMA（长期趋势）
  • 15分钟 20根K线 EMA（中期趋势）
  • 5分钟 20根K线 EMA（当前趋势）

设置原理​

通过在不同时间框架上显示EMA，可以同时观察短期、中期和长期趋势，帮助判断整体市场方向。

4. 交易室设置​

多图表布局​

交易室显示多个时间框架的图表：

  • 左侧：5分钟主图表（S&P500 Emini）
  • 右侧多个小图：
    • 60分钟图
    • 月线图
    • 周线图
    • 15分钟图
    • 日线图

为什么需要多时间框架​

  • 大局观：从 higher time frame 判断主要趋势
  • 入场时机：在 lower time frame 寻找精确入场点
  • 确认信号：多个时间框架共振增加胜率

5. 为什么你的图表与我的不同​

数据差异原因​

你的图表可能在均线上方，因为你使用的是：

  • 24小时数据（ETH - Extended Trading Hours）
  • 季度合约（而非连续合约）

我的图表有许多K线在均线下方，因为我使用的是：

  • 日间交易时段数据（RTH - Regular Trading Hours）
  • 连续合约

建议​

  • 使用日间交易时段数据（RTH）更符合实际交易情况
  • 使用连续合约避免换月跳空

6. 指标设置：15分钟和60分钟EMA在5分钟图上​

计算方法​

可以在任何平台上近似实现 Al Brooks 编程的EMA：

在5分钟图表上显示15分钟EMA：

  • 15分钟/5分钟 = 3
  • 设置EMA周期为 3 × 20 = 60（50更准确）

在5分钟图表上显示60分钟EMA：

  • 60分钟/5分钟 = 12
  • 设置EMA周期为 12 × 20 = 240（220更好）

7. TradeStation指标代码​

60分钟20根K线EMA代码​

Inputs:
  Length( 20 ),
  SessionEndTime(1315 {PST US Session});

If CurrentBar = 240 Then value1 = XAverage( C, 240 );
If CurrentBar > 240 Then
Begin
  If FracPortion( ( Time - 30 ) / 100 ) = 0 or Time = SessionEndTime Then
  Begin
    value1 = value1[1] + ( 2 / ( Length + 1 ) ) * ( C - value1[1] );
    value2 = value1;
    Plot1( value1, "60 min EMA" );
  End
  Else
  Begin
    value2 = value1 + ( 2 / ( Length + 1 ) ) * ( C - value1[1] );
    Plot1( value2, "60 min EMA" );
  End;
End;

注意：调整1315以匹配你所在时区的交易时段结束时间。1315是太平洋标准时间。

8. 日线、周线、月线图设置​

股票指数日线图设置​

S&P500现金指数日线图：

  • 200根简单移动平均线
  • 150根简单移动平均线
  • 100根简单移动平均线
  • 50根简单移动平均线

外汇日线图设置​

EUR/USD日线图：

  • 200根简单移动平均线
  • 150根简单移动平均线
  • 100根简单移动平均线
  • 50根简单移动平均线

总结要点​

设置项配置
主交易品种S&P500 ES Emini
主时间框架5分钟
多时间框架EMA5分钟、15分钟、60分钟（20根K线）
日线图均线50、100、150、200 简单移动平均线
数据类型日间交易时段（RTH）+ 连续合约
工作环境无干扰、无新闻、专注

关键原则​

  1. 专注是关键 - 消除所有干扰，包括新闻和专家意见
  2. 多时间框架分析 - 同时观察短期、中期和长期趋势
  3. EMA设置 - 使用正确的周期计算多时间框架EMA
  4. 数据一致性 - 使用日间交易时段数据和连续合约
  5. 简单移动平均线 - 日线图使用50/100/150/200 SMA
