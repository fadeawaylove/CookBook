# Al Brooks 课程图片章节总结任务

## 任务概览

本项目需要将 `docs/images/` 目录下的**156个子文件夹**（每个子文件夹代表一个课程章节）中的图片内容进行逐张总结，并更新到对应的 MkDocs 文档中。

**任务核心**：
1. **156个任务** = `docs/images/` 目录下的156个子文件夹
2. **每个任务** = 读取文件夹内所有图片 → 逐张分析总结 → 更新到 `docs/对应文件夹/index.md`
3. **单张图片处理流程**：查看图片内容 → 提取关键交易概念 → 编写文字总结 → 在文档中添加图片引用

## 工作方式

1. **逐个文件夹处理**：每个图片文件夹作为一个独立任务（共156个任务）
2. **逐张图片阅读**：读取文件夹中的每张图片，提取关键交易概念
3. **内容总结**：将每张图片的要点总结成文字，更新到对应文档
4. **图片引用**：在文档中添加每张图片的引用，使用 `../images/` 路径格式

- [ ] **任务1**：文档包含对应图片文件夹中的所有图片
- [ ] **任务2**：每张图片都有对应的文字总结
