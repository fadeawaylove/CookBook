# Gaps（缺口）

本章节介绍Brooks价格行为交易系统中关于缺口（Gap）的核心概念、识别方法以及如何利用缺口进行高效的交易决策。缺口是价格行为分析中的重要组成部分，掌握缺口的类型和特征对于提升交易胜率至关重要。


---

![缺口基础概念 - 什么是缺口](../images/11%20Gaps/slide01_image1.png)

**缺口基础概念 - 什么是缺口**：

此图展示了Brooks价格行为交易系统中关于缺口的进阶技术内容。通过分析缺口类型、价格行为、支撑阻力水平以及技术标注，交易者可以更准确地识别高概率交易机会。

**核心要点**：
- 理解不同类型的缺口（突破缺口、持续缺口、衰竭缺口、普通缺口）
- 掌握缺口与趋势的关系（启动、中继、结束）
- 识别缺口的支撑阻力作用（缺口回补与未回补）
- 结合其他技术工具确定入场点和止损位

**交易应用**：
缺口分析是Brooks交易系统的重要组成部分。通过系统化的缺口类型识别和结构分析，交易者可以在趋势启动、中继或结束时找到低风险的入场机会，同时保持较高的胜率。
