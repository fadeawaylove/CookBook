## 4. 图表差异解释

### 为什么你的图表与我的不同？

![图表差异解释](../images/04%20My%20Setup/slide04_image1.png)

**常见图表差异的原因：**

| 差异 | 你的图表 | Al的图表 |
|------|---------|---------|
| **数据时间** | 24小时数据 (ETH - 延长交易时段) | 日间交易时段 (RTH - 常规交易时段) |
| **合约类型** | 季度合约 | 连续合约 |
| **K线位置** | 许多K线在EMA上方 | 许多K线在EMA下方 |

**关键要点：**
- **ETH (Extended Trading Hours)** - 包含盘前盘后数据
- **RTH (Regular Trading Hours)** - 只包含常规交易时段 (9:30-16:00 ET)
- 使用不同类型的合约会导致价格差异

## 6. 技术指标配置

### 60分钟20周期EMA代码 (TradeStation)

![60分钟20周期EMA代码](../images/04%20My%20Setup/slide06_image1.png)

**TradeStation平台EMA指标代码示例：**

```pseudocode
Inputs:
    length( 20 ),
    SessionEndTime(1315 {PST US Session});

If CurrentBar = 240 Then value1 = Xaverage( C, 240 );
If CurrentBar > 240 Then
Begin
    If FracPortion( ( Time - 30 ) / 100 ) = 0 or Time = _SessionEndTime Then
    Begin
        value1[1] = ( value1[1] * ( 2 / ( _length + 1 ) ) ) * ( C - value1[1] );
        value2 = value1;
        Plot1( value1, "60 min EMA" );
    End
    Else
    Begin
        value2 = value1 + ( 2 / ( _length + 1 ) ) * ( C - value1[1]);
    End;
End;
```

**注意事项：**
- 调整1315以匹配你所在时区的交易时段结束时间
- 1315是太平洋标准时间

### 15分钟和60分钟EMA在5分钟图表上的设置

![15分钟和60分钟EMA设置](../images/04%20My%20Setup/slide07_image1.png)

**在5分钟图表上显示其他时间周期EMA的方法：**

**计算公式：**
- 周期倍数 = 目标时间周期 ÷ 图表时间周期

**15分钟EMA在5分钟图表上：**
```
15分钟 ÷ 5分钟 = 3
设置EMA周期为：3 × 20 = 60
(使用50更准确)
```

**60分钟EMA在5分钟图表上：**
```
60分钟 ÷ 5分钟 = 12
设置EMA周期为：12 × 20 = 240
(使用220更好)
```

## 总结

Al Brooks 的交易设置体现了**专业交易的核心原则**：

### 1. 环境与专注
- **消除干扰** - 百叶窗关闭、不接电话、不看电视
- **忽略新闻** - 只看价格行为，不听专家评论
- **极度专注** - 全神贯注于图表分析

### 2. 图表配置
- **主图表** - 5分钟S&P500 Emini
- **核心指标** - 20周期EMA（5/15/60分钟）
- **数据类型** - RTH常规交易时段（非ETH）
- **合约类型** - 连续合约（非季度合约）

### 3. 多时间周期分析
- **5分钟** - 主交易周期
- **15分钟** - 中期趋势确认
- **60分钟** - 长期趋势判断
- **日线/周线** - 宏观趋势背景

### 4. 技术实现
- **15分钟EMA在5分钟图** - 50周期
- **60分钟EMA在5分钟图** - 220周期
- **日线长期MA** - 50/100/150/200周期

通过理解和应用这些设置原则，交易者可以建立一个与Al Brooks类似的专业交易环境，为成功的价格行为交易奠定基础。
