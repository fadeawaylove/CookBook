# 14 Trends（趋势）

本章节介绍Brooks价格行为交易系统中关于趋势（Trends）的核心概念、识别方法以及如何利用趋势进行高效的交易决策。理解趋势的类型、特征和交易策略是价格行为交易的基础，对于把握市场方向、提高交易胜率至关重要。

## 趋势基础概念

趋势是市场价格运动的基本特征，识别趋势是交易决策的第一步。
