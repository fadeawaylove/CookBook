    04. 我的交易设置 (My Setup)

    本章节介绍 Al Brooks 的交易设置、工作环境以及图表配置，帮助交易者了解专业交易者的日常工作环境。

    1. 家庭办公室设置

    Al Brooks 的交易环境

    基本配置： - 笔记本电脑 - 主交易电脑 - 第二台电脑 - 专门用于聊天室（chat room） - 百叶窗关闭 - 避免外界干扰 - 不接电话、不看电视 - 保持专注

    交易原则： - 忽略新闻和专家评论 - 只看价格行为 - 不要任何干扰或他人意见 - 保持独立思考 - 非常专注 - 全神贯注于图表

    "我不想有任何干扰，也不想要任何人的意见。我非常专注。" — Al Brooks

    2. 交易理念

    交易的本质

    Al Brooks 的交易哲学：

    "我的工作是从你的账户里拿钱，放到我的账户里。" "你的工作是从我这里拿钱！" "这就是我们在玩的游戏！"

    这看似冷酷，但实际上揭示了交易的本质：这是一个零和博弈的游戏。理解这一点对成功交易至关重要。

    3. 图表设置

    5分钟 S&P500 Emini 图表

    Al Brooks 的主要交易图表配置：

    指标 设置 说明
    20周期EMA 5分钟图表 主要交易时间周期
    20周期EMA 15分钟图表 中期趋势参考
    20周期EMA 60分钟图表 长期趋势参考

    关键理解： - 20周期EMA 是 Al Brooks 交易系统中最重要的指标 - 不同时间周期的EMA提供不同层次的市场视角 - 5分钟是主要交易周期，但需要考虑更大时间周期的背景

    4. 图表差异解释

    为什么你的图表与我的不同？

    常见图表差异的原因：

    差异 你的图表 Al的图表
    数据时间 24小时数据 (ETH - 延长交易时段) 日间交易时段 (RTH - 常规交易时段)
    合约类型 季度合约 连续合约
    K线位置 许多K线在EMA上方 许多K线在EMA下方

    关键要点： - ETH (Extended Trading Hours) - 包含盘前盘后数据 - RTH (Regular Trading Hours) - 只包含常规交易时段 (9:30-16:00 ET) - 使用不同类型的合约会导致价格差异

    右上图 - 60分钟和日线图 - 更大时间周期的趋势判断 - 标注月度、周线关键水平 - 长期支撑阻力位

    右下图 - 15分钟图表 - 中间时间周期的确认 - 辅助判断入场时机

    6. 技术指标配置

    60分钟20周期EMA代码 (TradeStation)

    TradeStation平台EMA指标代码示例：

    Inputs:
    length( 20 ),
    SessionEndTime(1315 {PST US Session});

If CurrentBar = 240 Then value1 = Xaverage( C, 240 );
If CurrentBar > 240 Then
Begin
    If FracPortion( ( Time - 30 ) / 100 ) = 0 or Time = _SessionEndTime Then
    Begin
        value1[1] = ( value1[1] * ( 2 / ( _length + 1 ) ) ) * ( C - value1[1] );
        value2 = value1;
        Plot1( value1, "60 min EMA" );
    End
    Else
    Begin
        value2 = value1 + ( 2 / ( _length + 1 ) ) * ( C - value1[1]);
    End;
End;

    注意事项： - 调整1315以匹配你所在时区的交易时段结束时间 - 1315是太平洋标准时间

    15分钟和60分钟EMA在5分钟图表上的设置

    在5分钟图表上显示其他时间周期EMA的方法：

    计算公式： - 周期倍数 = 目标时间周期 ÷ 图表时间周期

    15分钟EMA在5分钟图表上： 

    15分钟 ÷ 5分钟 = 3
设置EMA周期为：3 × 20 = 60
(使用50更准确)

    60分钟EMA在5分钟图表上： 

    60分钟 ÷ 5分钟 = 12
设置EMA周期为：12 × 20 = 240
(使用220更好)

    总结

    Al Brooks 的交易设置体现了专业交易的核心原则：

    1. 环境与专注

    • 消除干扰 - 百叶窗关闭、不接电话、不看电视
    • 忽略新闻 - 只看价格行为，不听专家评论
    • 极度专注 - 全神贯注于图表分析

    2. 图表配置

    • 主图表 - 5分钟S&P500 Emini
    • 核心指标 - 20周期EMA（5/15/60分钟）
    • 数据类型 - RTH常规交易时段（非ETH）
    • 合约类型 - 连续合约（非季度合约）

    3. 多时间周期分析

    • 5分钟 - 主交易周期
    • 15分钟 - 中期趋势确认
    • 60分钟 - 长期趋势判断
    • 日线/周线 - 宏观趋势背景

    4. 技术实现

    • 15分钟EMA在5分钟图 - 50周期
    • 60分钟EMA在5分钟图 - 220周期
    • 日线长期MA - 50/100/150/200周期

    通过理解和应用这些设置原则，交易者可以建立一个与Al Brooks类似的专业交易环境，为成功的价格行为交易奠定基础。
